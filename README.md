# Mobile Phone Store Management System

A Java-based desktop application developed as a university group project to manage the daily operations of a mobile phone store.

## Overview

This project was built to support common business operations in a phone retail store, including product management, customer management, employee management and invoice processing.

The system demonstrates object-oriented programming concepts, database design, and CRUD operations using SQL Server.

## Features

- Product Management
- Customer Management
- Employee Management
- Invoice Management
- Search and Filter
- Database CRUD Operations
- User-friendly Desktop Interface

## Technologies

- Java
- Java Swing
- SQL Server
- JDBC
- Git & GitHub

## Project Structure

```
src/
database/
images/
```

## Requirements

- Java JDK 17 (or compatible version)
- SQL Server
- IDE (NetBeans / IntelliJ IDEA / Eclipse)

## Installation

1. Clone the repository

```bash
git clone https://github.com/Fierur/QL-Cua-Hang-Dien-Thoai.git
```

2. Import the project into your IDE.

3. Restore the SQL Server database.

4. Update the database connection configuration.

5. Run the application.
